老蔡正在使用WordPress 4.9.1，试了网上很多办法都无法正常让备案号显示在页脚，而备案托管方坚持不能把备案号放在网站友情链接中，于是自己折腾着解决了。 做到显示备案号2步即可完成。 1. 来到WordPress根目录，比如`/var/www/blog` 2\. 然后，修改文件

> ./wp-content/themes/twentyseventeen/template-parts/footer/site-info.php

原文件如下：

```php 找到以下代码
<?php
/\*\*
 \* Displays footer site info
 \*
 \* @package WordPress
 \* @subpackage Twenty_Seventeen
 \* @since 1.0
 \* @version 1.0
 */
?>
 <a href="<?php echo esc\_url( \_\_( 'https://wordpress.org/', 'twentyseventeen' ) ); ?>"><?php printf( __( 'Proudly powered by %s', 'twentyseventeen' ), 'WordPress' ); ?></a>
</div><!-- .site-info -->
```

修改后文件如下：

```php
<?php
/\*\*
 \* Displays footer site info
 \*
 \* @package WordPress
 \* @subpackage Twenty_Seventeen
 \* @since 1.0
 \* @version 1.0
 */
?>
 <a href="<?php echo esc\_url( \_\_( 'https://wordpress.org/', 'twentyseventeen' ) ); ?>"><?php printf( __( 'Proudly powered by %s', 'twentyseventeen' ), 'WordPress' ); ?></a>
 |
 <span><a href="http://www.miitbeian.gov.cn/" rel="external nofollow" target="_blank">哪ICP备XXXXXXXX号</a></span>
</div><!-- .site-info -->
```

显示效果如下： ![](/images/2017/12/20171212_12.jpg) 本方法可能只适用于WordPress 4，以后版本还需要验证，欢迎验证后的朋友留言告知。
