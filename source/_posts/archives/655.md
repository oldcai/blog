显示一下buildInfo就知道了 看**"bits" : 64**，就是64位的，相应的，32就是32位的。 老蔡用命令行登录查看作为测试，没有这个权限也可以自己用程序连接了后类似办法解决。

oldcai@ProBook:~$ mongo
MongoDB shell version: 2.0.4
connecting to: test
\> use admin
switched to db admin
\> db.runCommand("buildInfo")
{
	"version" : "2.0.4",
	"gitVersion" : "nogitversion",
	"sysInfo" : "Linux yellow 2.6.24-29-server #1 SMP Tue Oct 11 15:57:27 UTC 2011 x86\_64 BOOST\_LIB\_VERSION=1\_46_1",
	"versionArray" : \[
		2,
		0,
		4,
		0
	\],
	"bits" : 64,
	"debug" : false,
	"maxBsonObjectSize" : 16777216,
	"ok" : 1
}
